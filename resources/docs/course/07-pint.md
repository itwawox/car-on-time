# Pint — единый стиль кода

## Что это

Представьте книгу, где каждую главу набирал свой наборщик: разные шрифты, отступы, кавычки. Читать можно, но тяжело. **Pint** — это корректор, который приводит весь PHP-код проекта к одному оформлению.

Pint меняет **только внешний вид**: пробелы, отступы, переносы, порядок и лишние строки `use`. Смысл кода и работа сайта от этого **не меняются**.

## Зачем это нам

- Код читается одинаково, кто бы его ни писал: вы, другой программист или Claude.
- В Pull Request видны настоящие изменения, а не «тут переставили пробелы».
- Никто не спорит о стиле: правило одно, и следит за ним программа.

## Пример «до» и «после»

До:

```php
use Illuminate\Support\Str;
use App\Models\Car;
class Example{
    public function name(Car $car){
        if($car->name) return $car->name;
        return 'Без названия';
    }
}
```

После `./vendor/bin/pint`:

```php
use App\Models\Car;

class Example
{
    public function name(Car $car)
    {
        if ($car->name) {
            return $car->name;
        }

        return 'Без названия';
    }
}
```

Что поправил Pint:

- `use` отсортированы по алфавиту, неиспользуемый `Str` удалён;
- фигурные скобки перенесены на новые строки;
- пробелы после `if` расставлены;
- к однострочному `if` добавлены скобки.

## Команды

```bash
./vendor/bin/pint           # исправить стиль во всех файлах
./vendor/bin/pint --dirty   # только в файлах, которые вы поменяли (быстрее)
./vendor/bin/pint --test    # только проверить, ничего не меняя (так делает GitHub)
```

Если `--test` нашёл нарушения, GitHub покажет красный крестик. Исправление простое: запустить `./vendor/bin/pint` у себя и закоммитить.

## Где настройки

Стиль — стандартный для Laravel. Отдельного файла настроек у нас нет, Pint берёт стиль по умолчанию.

## Попробуйте сами

1. В любом PHP-файле уберите пробел после `if` (было `if (`, станет `if(`).
2. Запустите `./vendor/bin/pint --test` — он покажет файл с нарушением.
3. Запустите `./vendor/bin/pint` — пробел вернётся сам.
