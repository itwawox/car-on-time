# Структура проекта

Проект лежит в папке `~/Herd/rentacar`. Если открыть её в редакторе, сверху будут папки, ниже — отдельные файлы. У каждого своя роль: одни — сам Laravel, другие — библиотеки, третьи — настройки инструментов. Этот урок проходит по всем по порядку.

Серые названия в редакторе (`node_modules`, `vendor`, `.env` и другие) — это то, что **не хранится в git**: git их не видит, в GitHub они не попадают.

## Папки

| Что | К чему относится | Назначение |
|---|---|---|
| `.github/workflows` | GitHub | проверки на каждый Pull Request (`tests.yml`) и выкладка на хостинг (`deploy.yml`) |
| `app` | Laravel | весь PHP-код сайта: модели, контроллеры, админка, команды |
| `bootstrap` | Laravel | запуск приложения; `bootstrap/cache` — служебный кэш |
| `config` | Laravel | настройки: база, почта, файлы, приложение |
| `database` | Laravel | миграции (структура базы), фабрики для тестов, данные для первого наполнения |
| `deploy` | наш проект | скрипты выкладки на хостинг reg.ru |
| `lang` | Laravel | русские переводы служебных фраз |
| `node_modules` | npm | JS-библиотеки для сборки стилей; не редактируем, в git нет |
| `public` | Laravel | то, что браузер получает напрямую: `index.php`, иконки, собранные стили и скрипты |
| `resources` | Laravel | шаблоны страниц, CSS, JS, документация и этот курс |
| `routes` | Laravel | адреса сайта (`web.php`) и расписание фоновых задач (`console.php`) |
| `storage` | Laravel | загруженные фото, логи, кэш, копии базы; в git нет |
| `tests` | Pest | автотесты |
| `vendor` | Composer | PHP-библиотеки; не редактируем, в git нет |

## Файлы

| Что | К чему относится | Назначение |
|---|---|---|
| `.editorconfig` | редакторы | единые отступы и кодировка во всех редакторах |
| `.env` | Laravel | настройки этой копии сайта: база, пароли, ключ шифрования. **В git никогда** |
| `.env.example` | Laravel | образец `.env` без паролей — из него делают настоящий `.env` |
| `.gitattributes` | git | как git обращается с файлами: переносы строк, что не выгружать архивом |
| `.gitignore` | git | что git не отслеживает: `.env`, `vendor`, `node_modules`, `storage` и другое |
| `.npmrc` | npm | настройки npm |
| `.phpunit.result.cache` | Pest / PHPUnit | служебный файл тестов; в git нет |
| `artisan` | Laravel | служебный вход в сайт: `php artisan …` |
| `composer.json` | Composer | список PHP-библиотек, которые нужны сайту |
| `composer.lock` | Composer | точные версии этих библиотек — чтобы на всех компьютерах и на хостинге было одинаково |
| `package.json` | npm | список JS-библиотек и команды сборки (`npm run build`) |
| `package-lock.json` | npm | точные версии JS-библиотек |
| `phpstan.neon` | Larastan | настройки проверки кода: уровень строгости, какие папки проверять |
| `phpstan-baseline.neon` | Larastan | список старых замечаний, которые пока разрешены |
| `phpunit.xml` | Pest / PHPUnit | настройки тестов: база в памяти, очередь без задержек и прочее |
| `README.md` | GitHub | описание проекта — его показывает главная страница репозитория |
| `vite.config.js` | Vite | настройки сборки стилей и скриптов |

**Пары `.json` и `.lock`.** В `composer.json` написано `"laravel/framework": "^13.17"` — «Laravel 13, не ниже 13.17», а в `composer.lock` записана точная версия, которая стоит сейчас: `13.33.0`. Оба файла хранятся в git. Команда `composer install` ставит версии из `.lock`, поэтому на вашем компьютере, в GitHub и на хостинге они одинаковые. С `package.json` и `package-lock.json` так же.

## Файлы ИИ-помощников

Эти файлы — только на вашем компьютере: в `.gitignore`, в git и на хостинг не попадают. Для работы сайта они не нужны.

| Файл или папка | Для какой программы | Нужен ли |
|---|---|---|
| `CLAUDE.md` | Claude Code — правила проекта, которые помощник читает в начале каждой сессии | да, если работаете с Claude Code |
| `AGENTS.md` | общий файл правил для ИИ-помощников; `CLAUDE.md` его подключает | да, вместе с `CLAUDE.md` |
| `.claude/` | Claude Code: навыки по Laravel, Filament, тестам; локальные разрешения | да |
| `boost.json`, `.mcp.json` | Laravel Boost — даёт помощнику смотреть структуру базы и документацию Laravel нужной версии | полезно, не обязательно |
| `.cursor/` | редактор Cursor — копия тех же навыков | нет, если не пользуетесь Cursor |
| `.codex/` | Codex — помощник от OpenAI | нет, если не пользуетесь |
| `PLAN.md` | ваши заметки | план работ |

## Внутри `app` и `resources`

| Папка | Что внутри | Пример |
|---|---|---|
| `app/Models` | модели — описание таблиц базы | `Car.php`, `Booking.php` |
| `app/Http/Controllers` | контроллеры: принимают запрос и отдают страницу | `BookingController.php` |
| `app/Services` | большие расчёты и интеграции | `QuoteCalculator.php`, `Bitrix24Sync.php` |
| `app/Support` | небольшие помощники | `Phone.php`, `Backups.php` |
| `app/Jobs` | задания для очереди | отправка в CRM и SMS |
| `app/Console/Commands` | команды `php artisan …` | `BackupDatabase.php` |
| `app/Filament` | вся админка | разделы, таблицы, сводка, этот курс |
| `resources/views` | шаблоны страниц (Blade — HTML с вставками) | `car.blade.php` |
| `resources/css`, `resources/js` | стили и скрипты витрины | `app.css`, `app.js` |
| `resources/docs` | этот курс и документация для разработчиков | `course/`, `developers/` |

## Где искать, если нужно поменять…

| Задача | Куда смотреть |
|---|---|
| Текст на странице | сначала админка («Настройки сайта»), потом `resources/views` |
| Цвет или отступ | `resources/css/app.css`, потом `npm run build` |
| Как считается цена | `app/Services/QuoteCalculator.php` |
| Раздел в админке | `app/Filament` |
| Что происходит после заявки | `app/Http/Controllers/BookingController.php`, `app/Jobs` |
| Новое поле в базе | новая миграция в `database/migrations` |
| Проверку, которая упала | `tests/` — файл и строку Pest покажет сам |

## Попробуйте сами

1. Откройте `composer.json` и найдите строку с `laravel/framework` — это версия Laravel сайта.
2. Откройте папку `tests/Feature` и найдите файл, который проверяет промокоды. Подсказка: его имя начинается с `Promo`.
