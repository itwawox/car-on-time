# Все наши тесты: что проверяет каждый

Справочник по папке `tests`. Для каждого файла: **что он защищает** и что проверяет каждый тест внутри.

Запустить один файл:

```bash
./vendor/bin/pest tests/Feature/PromoCodeTest.php
```

> Этот урок проверяется тестом `CourseDocsTest.php`: если в папке `tests` появится новый файл, а здесь его нет, проверка упадёт. Добавили тест — допишите сюда строчку.

## Заявка и бронирование

### `BookingUxTest.php` — форма заявки и страница «Спасибо»

Защищает главный путь клиента: заявка «в три поля» и безопасная страница после неё.

- в карточке машины форма спрашивает только даты, место и телефон;
- заявка с минимумом данных принимается, место возврата по умолчанию — место выдачи;
- без телефона — понятная ошибка, а не «ошибка сервера»;
- без отдельной галочки согласия на обработку данных заявку не принять, время согласия сохраняется;
- страница «Спасибо» открывается только по подписанной ссылке — чужую заявку перебором номера не посмотреть;
- на «Спасибо» есть необязательный второй шаг «уточнить детали», тоже только по подписанной ссылке;
- детали сохраняются, доп. услуги пересчитывают итог;
- доп. услуги и промокод сохраняются в заявке и попадают в сообщение в Telegram;
- файл для календаря (.ics) выдаётся по подписи и правильного формата.

### `BookingWorkflowTest.php` — жизнь заявки в админке

Защищает занятость машин и работу менеджера.

- подтверждённая заявка занимает машину в календаре, отклонённая — освобождает;
- расчёт цены и каталог видят, что машина занята, с учётом времени на подготовку между арендами;
- смена статуса записывается с автором и временем первого ответа;
- заявку без ответа дольше нормы один раз поднимают в рабочий чат Telegram;
- менеджер не может подтвердить заявку на уже занятую машину;
- экраны заявок в админке открываются без ошибок.

### `BookingDocumentsTest.php` — документы клиента и акт осмотра

Защищает паспорта и права клиентов.

- клиент загружает документы в закрытое хранилище, менеджеру приходит уведомление;
- без согласия и без выбора типа документа загрузить нельзя;
- новый файл того же типа заменяет старый;
- после выдачи машины документы больше не принимаются;
- фото акта осмотра видны только по ссылке своей заявки, документы по ней не отдаются;
- документы автоматически удаляются через заданный в админке срок;
- менеджер видит в заявке разделы «Документы» и «Акт».

### `CabinetTest.php` — личный кабинет «Мои брони»

- гость видит вход по SMS, только если SMS включены;
- по коду из SMS клиент видит только свои брони, в каком бы формате ни ввёл телефон;
- после нескольких неверных попыток код сгорает;
- без SMS вход идёт через страницу заявки;
- заявка на продление считает доплату и уведомляет менеджера;
- продлить нельзя, если сразу после этой брони машина занята;
- нельзя продлить чужую бронь.

### `OwnerLeadTest.php` — заявки «Сдать авто» и обратный звонок

- страница для владельцев машин открывается, на неё есть ссылка;
- заявка владельца сохраняет марку, год и прочие детали;
- неправильно заполненная форма показывает ошибки;
- обычный «перезвоните мне» не сохраняет лишние поля;
- из заявки владельца в админке создаётся партнёр.

## Цена, промокоды, залог, оплата

### `QuoteCalculatorTest.php` — расчёт цены

- аренда считается по сезонным ценам за каждые сутки.

### `PromoCodeTest.php` — промокоды

- процентный код уменьшает аренду и в расчёте, и в заявке;
- фиксированная скидка никогда не больше стоимости аренды;
- если код не подходит (минимум суток, срок действия, класс машины, лимит использований), клиент видит причину и скидки нет;
- администратор создаёт и редактирует коды.

### `DepositWaiverTest.php` — «Без залога»

- услуга «Без залога» создаётся выключенной;
- она убирает залог и добавляет плату за сутки;
- выключенную услугу применить нельзя;
- клиент выбирает её на втором шаге заявки.

### `PrepaymentTest.php` — онлайн-предоплата через ЮKassa

- подтверждённой заявке предлагается предоплата с переходом в ЮKassa;
- новой неподтверждённой заявке кнопки оплаты нет;
- уведомление об оплате засчитывается только после проверки в ЮKassa и только один раз — поддельное «оплачено» не пройдёт;
- при возврате клиента со страницы оплаты статус обновляется, не дожидаясь уведомления;
- режим «оплата первых суток» и чек;
- уведомление о неизвестном платеже игнорируется.

## Интеграции и уведомления

### `Bitrix24IntegrationTest.php` — Битрикс24

- новая заявка становится сделкой с новым контактом и заполненными полями;
- существующий контакт используется повторно, а не дублируется;
- смена статуса двигает сделку по стадиям, новая сделка не создаётся;
- при выключенной интеграции ничего не отправляется;
- ошибка портала записывается в журнал, заявка принята;
- портал недоступен — заявка клиента всё равно принята;
- заявка «перезвоните» становится лидом;
- адрес вебхука хранится зашифрованным;
- входящий вебхук из Битрикс24 требует токен и меняет статус заявки;
- страницы админки открываются и не показывают адрес вебхука;
- «Проверить подключение» загружает справочники портала и не стирает сохранённый секрет.

### `CustomerNotificationsTest.php` — SMS клиенту

- после заявки клиент получает SMS с короткой ссылкой на статус;
- SMS о подтверждении берёт шаблон из админки;
- при выключенных SMS или событии ничего не отправляется;
- отказ SMS-провайдера пишется в журнал, заявка остаётся;
- страница статуса по короткой ссылке показывает этап заявки;
- напоминание и просьба об отзыве отправляются ровно один раз;
- поддерживается провайдер SMSC.

### `IntegrationSwitchesTest.php` — выключатели интеграций

- Telegram работает сразу, если бот настроен;
- выключатель Telegram отключает сообщения;
- аварийная команда отключает все интеграции, но ключи сохраняет.

### `AnalyticsAttributionTest.php` — метки рекламы (UTM) и Метрика

- в заявке сохраняются только известные метки;
- испорченные метки игнорируются;
- заявка «перезвоните» тоже хранит источник;
- UTM уходят в стандартные поля Битрикс24;
- на страницах есть данные для электронной коммерции Метрики.

## Каталог, поиск, подбор

### `CarSearchTest.php` — поиск машин на сайте

- находит по русскому написанию марки («хендай» → Hyundai);
- прощает опечатки и транслит;
- исправляет не ту раскладку;
- понимает слова-фильтры: «автомат до 3000», «7 мест»;
- скрытые машины не находятся;
- страница результатов закрыта от индексации;
- пустой поиск ведёт в каталог;
- подсказки при вводе показывают марки, машины и понятые фильтры;
- без запроса подсказки показывают популярные марки.

### `QueryIntentTest.php` — как поиск понимает запрос

- из запроса вынимаются фильтры, остальное остаётся текстом;
- понимает привод, топливо, число мест и слово «дешёвый»;
- слово «цена» без числа игнорируется.

### `SearchAdminTest.php` — «Умный поиск» в админке

- словари загружаются в базу;
- синоним, добавленный в админке, работает сразу;
- второе название марки из админки используется;
- слова-фильтры и тексты поиска редактируются;
- тексты страницы поиска берутся из настроек;
- запросы записываются в журнал, короткие пропускаются;
- один посетитель считается один раз, разные — складываются;
- запрос без результатов можно превратить в синоним;
- страницы админки поиска открываются.

### `SearchWeightsTest.php` — веса полей поиска

- веса полей из «Настроек поиска» действительно влияют на результат. Этот тест поймал реальный баг — см. урок «Larastan».

### `QuizTest.php` — подбор за 30 секунд

- для командировки не предлагается дешёвая механика эконом-класса;
- для компании — машины с нужным числом мест, для гор — полный привод, для отдыха — кабриолет;
- «только автомат» соблюдается, а если по бюджету машин нет — бюджет ослабляется честно, и это видно;
- страницы подбора и счётчик машин работают, старые ссылки не ломаются;
- тексты подбора редактируются в настройках.

### `SmartPickTest.php` — умные подсказки в карточке

- характеристики берутся сначала из машины, потом из модели, считается стоимость топлива;
- альтернативы: дешевле, мощнее, экономичнее — с разницей в цене, без повторов;
- для машины с механикой предлагается автомат;
- пакетный расчёт цены за период соблюдает минимальный срок;
- сортировка каталога закрыта от индексации и работает по мощности;
- «похожие на просмотренные» не показывают уже просмотренные.

### `UxFeaturesTest.php` — фильтры, избранное, заявки

- фильтры каталога сочетаются, счётчик совпадает со списком;
- пакетный расчёт добавляет доставку в выбранное место;
- акции показываются только активные и попадают в карту сайта;
- заявки «перезвоните» и от юрлиц сохраняются;
- страница избранного закрыта от индексации и показывает машины.

### `CompareTest.php` — сравнение

- на странице сравнения до трёх машин, она закрыта от индексации.

### `CarContentTest.php` — описания машин

## SEO и технические вещи

### `SeoPagesTest.php`

- карта сайта, страницы городов и подбора открываются;
- расчёт цены «на лету» отдаёт правильный JSON;
- постраничная навигация каталога — с красивыми адресами.

### `SeoTechnicalTest.php`

- шаблоны мета-тегов редактируются, поля конкретной страницы важнее шаблона;
- в заголовке страницы 2, 3… не ломается название бренда;
- новые страницы сами попадают в карту сайта, пустые и скрытые — нет;

- страницы городов берутся из базы;
- адрес со слэшем на конце перенаправляется, страница 404 — фирменная;
- `robots.txt` закрывает не-боевые сайты, ключ IndexNow отдаётся;

### `SecurityHeadersTest.php` — заголовки безопасности

- строгий HTTPS (HSTS) включается только на боевом сайте по https.
