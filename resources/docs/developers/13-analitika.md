# Аналитика: цели Метрики и источники заявок

## Что сайт отправляет в Яндекс Метрику

Счётчик включается, если в **SEO → Настройки SEO** указан номер счётчика Метрики, и только после того, как посетитель нажал «Принять все» в баннере cookie (требование 152-ФЗ). До согласия ничего не отправляется.

Сайт сам отправляет такие **цели** (события):

| Идентификатор цели | Когда срабатывает |
|---|---|
| `car_view` | открыта карточка машины |
| `dates_selected` | в карточке выбраны даты |
| `booking_form_start` | посетитель начал заполнять форму заявки |
| `promo_applied` | на странице «Заявка принята» клиент ввёл промокод, и он дал скидку |
| `booking_submit` | нажата кнопка отправки заявки на бронь |
| `booking_sent` | заявка принята (страница «Спасибо»); передаётся сумма заявки |
| `lead_submit` | отправлена форма «Перезвоните мне», «Для юрлиц» или «Сдать авто» |
| `phone_click` | клик по номеру телефона |
| `messenger_click` | клик по WhatsApp, Telegram или MAX |
| `search` | поиск по сайту |
| `quiz_result` | пройден подбор машины |

Кроме того, включена **электронная коммерция**: просмотр машины и «покупка» (отправленная заявка с суммой). Отчёты — в Метрике: **Отчёты → Электронная коммерция**.

## Как завести цели в Метрике (делается один раз)

1. Откройте https://metrika.yandex.ru → ваш счётчик → **Настройки → Цели → Добавить цель**.
2. Тип цели — **JavaScript-событие**.
3. Название — любое понятное («Заявка отправлена»), **идентификатор** — ровно как в таблице выше, например `booking_sent`.
4. Повторите для нужных целей. Для рекламы главная — `booking_sent`.
5. Электронная коммерция: **Настройки → Счётчик → Электронная коммерция** → включить, контейнер данных `dataLayer`.

## Откуда пришёл клиент (UTM-метки)

При первом заходе браузер запоминает источник на 30 дней: UTM-метки из ссылки рекламы (`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`), метки кликов `yclid` (Яндекс Директ) и `gclid` (Google), сайт, с которого перешли, и первую страницу. С заявкой и обращением источник сохраняется в базе.

Где его видно:

- в админке: карточка заявки → «Расчёт на сайте» → **Источник трафика**; в списке заявок — колонка «Трафик» (включается кнопкой настройки колонок);
- в Telegram-уведомлении менеджерам — строка «Трафик»;
- в Битрикс24 — стандартные поля сделки или лида `UTM_SOURCE`, `UTM_MEDIUM`, `UTM_CAMPAIGN`, `UTM_CONTENT`, `UTM_TERM`. По ним работают отчёты CRM по рекламе.

Чтобы источник определялся, в рекламе ставьте ссылки с метками, например:
`https://car-on-time.ru/?utm_source=yandex&utm_medium=cpc&utm_campaign=leto-2026`

## Где в коде

- `resources/js/analytics.js` — цели, электронная коммерция, запоминание источника;
- `app/Support/Attribution.php` — проверка и сохранение источника на сервере;
- код счётчика — `resources/views/layouts/app.blade.php`.
