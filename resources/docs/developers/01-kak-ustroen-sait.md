# Как устроен сайт: где что хранится

Главное, что нужно понять: у сайта **пять разных видов «содержимого»**, и каждое попадает на боевой сервер своим путём. Почти все вопросы «почему у меня локально так, а на сайте иначе» объясняются этой таблицей.

| Что | Примеры | Где живёт | Как попадает на боевой сайт |
|---|---|---|---|
| **1. Код и оформление** | шаблоны страниц, стили, скрипты, PHP, иконка сайта `public/favicon.svg`, знак логотипа в `resources/views/partials/logo.blade.php` | в GitHub (репозиторий) | через GitHub: коммит → пуш → мерж в `main` → GitHub сам выкладывает |
| **2. Структура базы данных** | «в карточке машины появилось новое поле», новая таблица «Промокоды» | в коде, в папке `database/migrations` | вместе с кодом; на хостинге её применяет команда `php artisan migrate` (выкладка запускает её сама) |
| **3. Данные в базе** | машины, цены, тексты из «Настроек сайта», надпись логотипа, заявки, отзывы, пользователи админки | в базе данных **каждого** сайта отдельно | **никак автоматически**. Локальная база и боевая — две разные базы. Меняйте в админке боевого сайта (или через «миграцию с данными», см. раздел 5) |
| **4. Загруженные файлы** | фото машин, обложки статей и акций | папка `storage/app/public` на **каждом** сервере отдельно | не через GitHub. Загружайте через админку боевого сайта (или копируйте файлы, см. раздел 6) |
| **5. Секреты и настройки хостинга** | пароль базы, `APP_KEY`, домен | файл `.env` на хостинге | только руками на хостинге. **Никогда** не попадают в GitHub |

## Короткие ответы на частые вопросы

**«Мы добавили новые поля в карточку автомобиля — как перезалить сайт?»**
Поля в базе добавляются *миграцией* — это маленький файл с инструкцией «добавь колонку». Он лежит в коде. Вы отправляете код в GitHub и вливаете в `main` — GitHub сам выложит сайт и применит миграцию. **Существующие машины, заявки и тексты останутся на месте**: миграция только добавляет колонку. Подробно — раздел «Изменения базы данных».

**«Я локально поменял логотип, а на боевом сайте старый — как обновить?»**
Зависит от того, *что* вы поменяли:
- надпись «Car On Time» и подпись под ней — это **данные** (Сайт → Настройки сайта → Логотип). Их нужно так же поменять в админке **боевого** сайта. GitHub тут не участвует;
- сам значок (картинка) или иконка во вкладке браузера — это **код** (`partials/logo.blade.php`, `public/favicon.svg`, `public/icon-*.png`). Их нужно закоммитить, запушить и влить в `main`.

**«Я добавил машину или поменял цены у себя на компьютере — почему на сайте нет?»**
Потому что это данные в *локальной* базе. Работайте с машинами, ценами и текстами сразу в админке боевого сайта: https://car-on-time.ru/admin.

## Правило, которое спасает от 90% проблем

> Код меняем **только локально** и доставляем **только через GitHub**.
> Данные (машины, цены, тексты, фото) меняем **только в админке боевого сайта**.

Если на хостинге поправить файл руками, следующая выкладка молча затрёт правку.
