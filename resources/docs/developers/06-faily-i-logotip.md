# Файлы, картинки и логотип

## Где что лежит

| Что | Где хранится | Как поменять на боевом сайте |
|---|---|---|
| Фото машин, обложки статей и акций | `storage/app/public` на хостинге (в GitHub **нет**) | загрузить через админку боевого сайта |
| Надпись логотипа «Car On Time» и подпись «машина вовремя» | база данных: Сайт → Настройки сайта → **Логотип** | поменять в админке боевого сайта |
| Значок логотипа (часы с галочкой) | код: `resources/views/partials/logo.blade.php` | коммит → пуш → мерж в `main` |
| Иконка во вкладке браузера | код: `public/favicon.svg`, `public/favicon.ico` | коммит → пуш → мерж в `main` |
| Иконки для телефона (ярлык на экране) | код: `public/apple-touch-icon.png`, `public/icon-192.png`, `public/icon-512.png`, `public/icon-maskable-512.png` | коммит → пуш → мерж в `main` |
| Картинка для превью ссылки в мессенджерах | код: `public/og-image.jpg` | коммит → пуш → мерж в `main` |

## Как заменить логотип целиком

1. Надпись — в админке боевого сайта: **Сайт → Настройки сайта → Логотип**, «Сохранить».
2. Значок и иконки:
   - замените файлы в `public/` на новые **с теми же именами и размерами** (favicon.svg — векторный; icon-192.png — 192×192 пикселя и т. д.);
   - если значок рисуется в `partials/logo.blade.php` (он там SVG-кодом) — замените SVG-код на свой;
   - проверьте на http://rentacar.test, закоммитьте, запушьте, влейте в `main`.
3. Браузеры долго помнят старую иконку во вкладке. Проверяйте в режиме «Инкогнито».

## Перенести загруженные фото между компьютером и хостингом

Обычно не нужно: фото загружают сразу в боевую админку. Если всё же надо (например, первая заливка сайта), с вашего компьютера:

```bash
# с компьютера на хостинг
rsync -avz ~/Herd/rentacar/storage/app/public/ u1234567@server123.hosting.reg.ru:car-on-time/storage/app/public/

# с хостинга на компьютер (получить настоящие фото для локальной копии)
rsync -avz u1234567@server123.hosting.reg.ru:car-on-time/storage/app/public/ ~/Herd/rentacar/storage/app/public/
```

Внимание: копировать файлы без базы бессмысленно — база помнит, какое фото к какой машине. Переносите их вместе (раздел «Локальная разработка»).

**Правила работы с `rsync`:**

- **Сначала пробный запуск** с флагом `-n` (и `--stats` для итога): `rsync -avzn --stats …`. Он ничего не меняет, только показывает, что будет скопировано. Строк `deleting` быть не должно.
- **Слэш на конце источника** (`…/public/`) — копировать содержимое папки. Без него на сервере появится вложенная `public/public`.
- **Без `--delete`** `rsync` ничего не удаляет на стороне получателя. С `--delete` удалит всё, чего нет у источника. Для фото его не используйте.
- **Повторный запуск безопасен**: передаются только новые и изменённые файлы.
- **Ключ выкладки:** если вход на сервер по ключу, добавьте `-e "ssh -i ~/.ssh/имя-ключа"`.
- **Проверка:** число файлов на обеих сторонах должно совпасть: `find storage/app/public -type f | wc -l` локально и то же через `ssh` на сервере.

Подробный пример с тестовым сайтом — **Курс → «База и картинки на тестовом сайте»**.
