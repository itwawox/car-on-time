# Онлайн-предоплата (ЮKassa)

## Как это выглядит для клиента

1. Клиент оставляет заявку — как и раньше, **без предоплаты**.
2. Менеджер проверяет наличие и ставит статус «Предложили клиенту» или «Подтвердить».
3. На странице заявки (ссылка из SMS `/b/…`) появляется блок **«Закрепите машину за собой»** с кнопкой **«Внести предоплату N ₽»**.
4. Кнопка ведёт на платёжную страницу ЮKassa: карты МИР, СБП и другие способы, которые включены в вашем магазине ЮKassa.
5. После оплаты клиент возвращается на страницу заявки и видит «Предоплата получена» и сколько осталось заплатить при получении. Менеджерам приходит сообщение в Telegram, в истории заявки — запись «Оплата».

Предоплата — **по желанию клиента**: без неё заявка тоже действует. Кнопка не показывается для новых заявок (наличие ещё не подтверждено), после начала аренды и если уже оплачено.

## Подключение (один раз)

1. Зарегистрируйте магазин на https://yookassa.ru (нужны ИП или ООО). Дождитесь проверки.
2. В личном кабинете ЮKassa:
   - **Интеграция → Ключи API** — выпустите секретный ключ; там же виден **shopId**;
   - **Интеграция → HTTP-уведомления** — вставьте адрес `https://car-on-time.ru/integrations/yookassa/webhook` и отметьте события **payment.succeeded** и **payment.canceled**;
   - если подключаете чеки (54-ФЗ) — раздел **Чеки**: онлайн-касса или «Чеки от ЮKassa».
3. В админке сайта: **Интеграции → Интеграции → «Онлайн-предоплата (ЮKassa)»**:
   - включите «Принимать предоплату онлайн», вставьте shopId и секретный ключ;
   - выберите размер: процент от суммы (по умолчанию 15%), стоимость первых суток или фиксированная сумма;
   - если чеки подключены — включите «Отправлять чек» и выберите ставку НДС (для большинства ИП на упрощёнке — «Без НДС»);
   - «Сохранить», затем кнопка **«Проверить ЮKassa»** вверху страницы.
4. Для проверки можно сначала использовать **тестовый магазин** ЮKassa (свои shopId и ключ, тестовые карты из документации ЮKassa), потом заменить ключи на боевые.

## Надёжность

- Статусу из браузера и из уведомления сайт не верит: всегда переспрашивает ЮKassa по номеру платежа.
- Повторные уведомления не засчитывают оплату дважды.
- Все обращения к ЮKassa — в **Интеграции → Журнал обмена** (система «Оплата»).
- Платежи по заявке видны в её карточке, раздел «Онлайн-оплата»; в списке заявок под суммой — «оплачено N ₽».

## Возвраты

Возврат предоплаты (отказ клиента, машина сломалась) делается в личном кабинете ЮKassa: **Платежи → найти платёж → Вернуть**. Номер заявки указан в описании платежа.

## Где в коде

- `app/Services/Payments/` — настройки, клиент API ЮKassa, логика предоплаты;
- `app/Http/Controllers/PaymentController.php` — кнопка оплаты и уведомления ЮKassa;
- тексты блока предоплаты — **Сайт → Настройки сайта → Страница статуса заявки**.
