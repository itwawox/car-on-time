# Ближайшая выкатка: что нового и чек-лист

Новые возможности сделаны в ветке `feature/enterprise`: интеграции (Битрикс24, SMS), роли в админке, календарь занятости, CRM-экран заявок, промокоды, дашборд, аналитика, онлайн-предоплата, простая заявка «в три поля», опция «без залога», личный кабинет клиента, документы заранее и акт осмотра, автоматическая выкладка через GitHub, эта документация. Чтобы они появились на боевом сайте, нужно один раз настроить выкладку и влить ветку в `main`.

## Чек-лист

1. **Настроить хостинг и GitHub** — раздел «Первая настройка хостинга reg.ru»: PHP 8.4, SSH, SSH-ключ, секреты и переменная `DEPLOY_ENABLED` в GitHub, `.env`, корневая папка `public`, CRON.
   Если сайт уже работает на reg.ru, шаги 1 (база), 5 (`.env`) и 6 (корневая папка), скорее всего, уже сделаны — проверьте, что в `DEPLOY_PATH` указана именно папка текущего сайта.
2. **Проверить CRON.** Без него не будут работать фоновая очередь (отправка в Битрикс24 и SMS), напоминания о просроченных заявках и SMS-напоминания клиентам, ночные копии базы.
3. **Влить ветку в `main`**: GitHub → Pull Request `feature/enterprise → main` → дождаться зелёной галочки тестов → **Merge**. GitHub сам выложит сайт: применит новые миграции, соберёт стили, обновит кэши.
4. **Проверить вход в админку.** Раньше на боевом сайте вход не работал бы ни у кого: Filament без проверки прав пускает только в локальном режиме. Теперь доступ по ролям, и все, кто уже был в админке, стали **владельцами**. Если войти не получается: по SSH `cd ~/car-on-time && /opt/php/8.4/bin/php artisan user:owner ваш@email.ru`.
5. **Раздать роли сотрудникам**: **Интеграции → Сотрудники** — менеджерам роль «Менеджер», редактору — «Контент-редактор».
6. **Настроить интеграции** (**Интеграции → Интеграции**): Telegram-чат, срок ответа на заявку, при желании Битрикс24, SMS и онлайн-предоплату ЮKassa.
7. **Завести цели в Яндекс Метрике** — раздел «Аналитика».
8. **Поднять лимит загрузки файлов в PHP** (панель reg.ru): `upload_max_filesize = 10M`, `post_max_size = 48M` — иначе клиенты не смогут загрузить фото документов с телефона.
9. **Решить про «Без залога»**: выкладка создаёт в **Справочники → Доп. услуги** выключенную услугу «Без залога» (снимает залог за доплату в сутки). Чтобы предлагать её клиентам — укажите цену в сутки и включите «Показывать клиентам». Клиент выбирает её на втором шаге после заявки, в расчёте на карточке машины появится подсказка «можно без залога».

## Роли в админке

| Роль | Что видит |
|---|---|
| Владелец | всё, включая интеграции, сотрудников, журнал обмена, комиссию партнёров, эту документацию |
| Менеджер | заявки, календарь занятости, обращения, парк, справочники, отзывы, дашборд |
| Контент-редактор | статьи, страницы, FAQ, акции, промокоды, SEO, настройки текстов сайта, отзывы |
