# Словарь для начинающих

| Слово | Что это простыми словами |
|---|---|
| **Git** | Программа, которая помнит всю историю изменений кода: кто, что и когда поменял. Позволяет вернуться к любой прошлой версии. |
| **GitHub** | Сайт, где хранится общая копия кода: https://github.com/itwawox/car-on-time. С него код забирает сервер. |
| **Репозиторий (репо)** | Папка проекта вместе со всей историей изменений. |
| **Коммит (commit)** | Сохранённый «снимок» изменений с подписью, например «Добавили поле „Цвет“». |
| **Ветка (branch)** | Параллельная линия работы. `main` — главная ветка, **то, что на боевом сайте**. Новую работу делают в отдельной ветке, чтобы не сломать `main`. |
| **Пуш (push)** | Отправить свои коммиты с компьютера в GitHub. |
| **Пулл (pull)** | Забрать свежие коммиты из GitHub к себе (или на сервер). |
| **Pull Request (PR)** | Заявка в GitHub «влейте мою ветку в `main`». Там видно все изменения, их можно проверить до выкладки. |
| **Мерж (merge)** | Влить одну ветку в другую, например готовую ветку в `main`. |
| **Хостинг / боевой сайт / прод** | Место в интернете, где работает https://car-on-time.ru. У нас — обычный хостинг reg.ru. |
| **Локальный сайт** | Копия сайта на вашем компьютере: http://rentacar.test (через Laravel Herd). Её можно ломать без последствий. |
| **SSH** | Способ подключиться к хостингу и вводить там команды. Команда вида `ssh u1234567@server123.hosting.reg.ru`. |
| **Деплой (deploy)** | Обновление боевого сайта свежим кодом. У нас его делает GitHub сам после мержа в `main`. |
| **База данных (БД)** | Хранилище машин, цен, заявок, текстов. У локального и боевого сайта **разные** базы. |
| **Миграция** | Файл-инструкция «как изменить структуру базы»: добавить таблицу, колонку. Лежит в `database/migrations`. |
| **`.env`** | Файл с секретами и настройками конкретного сервера (пароль базы и т. п.). В GitHub его нет и быть не должно. |
| **Cron** | Будильник хостинга: раз в минуту запускает `php artisan schedule:run`, а тот — фоновые задачи. Настраивается в панели reg.ru. |
| **Очередь (queue)** | Список фоновых задач: отправить заявку в Битрикс24, SMS клиенту. Разбирается по будильнику cron. |
| **Artisan** | Командная строка Laravel: `php artisan …`. Через неё делаются миграции, кэши, резервные копии. |
| **GitHub Actions** | Роботы GitHub: проверяют код тестами и выкладывают сайт на хостинг. Вкладка **Actions** в репозитории. |
| **Composer / npm** | Установщики библиотек: Composer — для PHP, npm — для стилей и скриптов. |
| **Сборка (build)** | `npm run build` — превращает исходные стили и скрипты в готовые файлы для браузера в `public/build`. |
